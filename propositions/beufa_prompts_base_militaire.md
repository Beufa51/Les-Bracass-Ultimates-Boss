# Beufa — V59 : prompts « base militaire » (nouveaux décors)

Même style que les autres décors. À la livraison : déposer dans `assets_inbox/` sous le nom `<nom>_3q.jpg`
(ex. `beufa_drapeau_3q.jpg`) et le dire à Claude. Les panneaux n'ont VOLONTAIREMENT pas de lettres
(les générateurs écrivent mal) : pictogrammes seulement. Les lignes de places du parc : dessinées par le code, pas de prompt.
