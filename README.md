# Les Bracass'

Jeu 2D dans le navigateur : un hub, 6 portes, 6 boss, 6 badges.

**Jouer en ligne :** https://beufa51.github.io/Les-Bracass-Ultimates-Boss/

**Jouer sur son ordinateur (facultatif) :** double-clic sur `lancer.bat` (Windows) ou `lancer.command` (Mac).
Nécessite Python (gratuit, https://www.python.org).

Commandes : flèches, Espace, Z, X. Menu de test caché : F1.
Sur smartphone ou tablette : des boutons tactiles apparaissent à l'écran (tenir le téléphone à l'horizontale).

Voir `NOTES.md` pour l'état du projet.
